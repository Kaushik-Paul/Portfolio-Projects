# Product Overview

Personal portfolio website for Kaushik Paul showcasing fullstack and AI development projects.

- Live at: https://projects.kaushikpaul.co.in/
- Companion to main site: https://www.kaushikpaul.co.in/
- Hosted on Cloudflare Pages with custom domain via Cloudflare DNS
- Static site — no backend, no build step, no framework

The site has three sections: Hero (intro), Projects (card grid linking to redirect/launch pages), and About (bio + skills). Each project card links to an intermediate redirect page that auto-redirects to the external project URL after 3 seconds.

A custom 404 page with animated background elements handles unknown routes.
